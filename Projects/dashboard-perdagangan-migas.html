Dashboard Perdagangan Migas Indonesia

BPS 1996–2024 Power BI Excel

Dashboard interaktif yang menganalisis perkembangan perdagangan migas Indonesia periode 1996–2024 melalui nilai ekspor, impor, neraca perdagangan, dan komposisi komoditas.

Project Overview

Project Overview

Project Background

Perdagangan migas merupakan salah satu indikator penting dalam aktivitas perdagangan internasional Indonesia. Dashboard ini dikembangkan untuk menyajikan data ekspor, impor, dan neraca perdagangan migas secara visual sehingga tren serta komposisi perdagangan dapat dianalisis dengan lebih mudah.

Questions

  • Bagaimana perkembangan nilai ekspor dan impor migas Indonesia selama periode 1996–2024?
  • Bagaimana perubahan neraca perdagangan migas dari tahun ke tahun?
  • Apakah perdagangan migas Indonesia cenderung mengalami surplus atau defisit pada periode tertentu?
  • Komoditas migas apa yang menjadi komoditas utama dalam ekspor dan impor?
  • Bagaimana perubahan komposisi komoditas migas terhadap nilai perdagangan Indonesia?

Data Preparation

Data Preparation

Data Cleaning

  • Memeriksa nilai kosong (missing values).
  • Menyesuaikan tipe data.
  • Menghapus data yang tidak diperlukan.
  • Menyeragamkan format penamaan.

Data Transformation

  • Transformasi data menggunakan Power Query.
  • Mengelompokkan data berdasarkan tahun, komoditas, dan jenis perdagangan.
  • Menggabungkan (merge) data nilai dan volume.
  • Menyiapkan field yang digunakan pada dashboard.

Insights

Insights

Key Findings

  • Neraca perdagangan migas menunjukkan tren surplus pada awal periode, kemudian beralih menjadi defisit dalam beberapa tahun terakhir.
  • Nilai impor migas secara umum lebih tinggi dibandingkan nilai ekspor sehingga menghasilkan defisit perdagangan.
  • Gas alam menjadi komoditas ekspor utama, sedangkan impor didominasi oleh minyak mentah dan hasil minyak.

Recommendations

  • Meningkatkan nilai tambah komoditas migas dalam negeri untuk mengurangi ketergantungan impor.
  • Memperkuat produksi dan efisiensi sektor migas guna memperbaiki neraca perdagangan.
