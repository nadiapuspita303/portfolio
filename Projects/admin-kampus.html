Sampel Soal – Administrasi Kampus

Microsoft Excel

Workbook ini dirancang untuk untuk menguji kemampuan dalam mengolah data administrasi kampus menggunakan Microsoft Excel.

Project Overview

Project Overview

Project Background

Project ini merupakan simulasi pengolahan data administrasi kampus menggunakan Microsoft Excel yang bertujuan melatih kemampuan mengelola informasi akademik secara sistematis. Studi kasus mencakup pengolahan data mahasiswa, transaksi akademik, serta rekapitulasi informasi menggunakan berbagai fungsi Excel. Melalui project ini, saya menerapkan formula dan teknik pengolahan data untuk menghasilkan informasi yang lebih akurat, terstruktur, dan siap digunakan dalam proses administrasi.

Project Objective

Project ini bertujuan untuk meningkatkan kemampuan dalam mengolah data administrasi kampus menggunakan Microsoft Excel melalui penerapan fungsi dan formula yang sesuai dengan kebutuhan operasional. Selain melatih pemahaman terhadap struktur dan relasi antar data, project ini juga mengembangkan ketelitian, kemampuan analisis, serta penyelesaian permasalahan dalam menghasilkan informasi administrasi yang akurat dan konsisten.

Task / Use Case

Task / Use Case

Ringkasan singkat tugas atau skenario penggunaan yang diselesaikan pada sampel soal ini.

  • Mengidentifikasi kode program studi dari format ID Registrasi menggunakan fungsi pengolahan teks di Microsoft Excel.
  • Menghubungkan data mahasiswa dengan tabel referensi (master data) untuk memperoleh informasi program studi dan tarif per SKS.
  • Menentukan status akademik mahasiswa berdasarkan tahun masuk menggunakan logika kondisi.
  • Menghitung jumlah SKS yang dapat diambil berdasarkan kategori IPK simulasi.
  • Menghitung total biaya semester secara otomatis dengan mengombinasikan beberapa data referensi dan perhitungan.
  • Menyusun formula yang dapat diterapkan secara konsisten pada seluruh data tanpa melakukan input manual.

Process / Workflow

Process / Workflow

1

Dataset

Memahami struktur dataset, relasi antar tabel, serta kebutuhan informasi yang harus dihasilkan. Kemudian, mengekstraksi kode program studi dari ID Registrasi menggunakan fungsi pengolahan teks.

2

Penggunaan Rumus

Melakukan lookup ke tabel referensi untuk memperoleh nama program studi dan tarif per SKS, menyusun logika IF bertingkat untuk menentukan status akademik, jumlah SKS, dan biaya kuliah pokok berdasarkan aturan yang telah ditentukan serta menghitung total biaya semester dengan menggabungkan hasil lookup dan perhitungan matematis.

3

Pengecekan Akhir

Memastikan seluruh rumus menggunakan referensi yang tepat sehingga dapat diterapkan ke seluruh baris data dan melakukan pengecekan akhir untuk memastikan seluruh hasil perhitungan telah sesuai dengan ketentuan soal.

Key Features

Key Features

  • Pengolahan data berbasis formula tanpa input manual.
  • Penerapan logika IF bertingkat untuk klasifikasi data akademik.
  • Lookup data referensi menggunakan VLOOKUP.
  • Perhitungan otomatis biaya semester berdasarkan beberapa variabel.
  • Struktur workbook yang rapi dan mudah dipahami.
  • Penggunaan referensi absolut dan relatif untuk mempercepat pengisian rumus.
  • Formula yang dapat di-drag dan diterapkan secara konsisten pada seluruh data.
  • Dataset yang merepresentasikan proses administrasi akademik di lingkungan perguruan tinggi.
