Data Hasil Belajar Siswa (Microsoft Excel)

Microsoft Excel Formula Excel Dashboard

Workbook Microsoft Excel untuk pengolahan dan administrasi data nilai siswa menggunakan rumus, PivotTable, dan fitur administrasi lainnya.

Project Overview

Project Overview

Project Background

Pengolahan nilai siswa sering dilakukan secara manual sehingga memerlukan waktu lebih lama dan berisiko terjadi kesalahan perhitungan.

Project Objective

Mengurangi waktu pengolahan nilai siswa dan mengurangi risiko kesalahan perhitungan melalui otomatisasi menggunakan Microsoft Excel.

Task / Use Case

Task / Use Case

Ringkasan singkat tugas atau skenario penggunaan yang diselesaikan workbook ini.

  • Membuat formula untuk menghitung nilai akhir dan grade siswa.
  • Membuat PivotTable untuk menganalisis data nilai siswa berdasarkan kelas atau mata pelajaran.
  • Mengembangkan dashboard interaktif untuk menampilkan informasi penting secara visual.

Process / Workflow

Process / Workflow

1

Input Data Nilai Siswa

Memasukkan data nilai siswa ke dalam sheet yang tersedia.

2

Menghitung Nilai Rata-Rata dan Status Kelulusan

Menggunakan rumus Excel untuk menghitung nilai rata-rata berdasarkan mata pelajaran dan menentukan status kelulusan siswa.

3

Mengembangkan Dashboard Analisis

Menggunakan PivotTable dan PivotChart untuk menampilkan analisis data nilai siswa secara visual.
