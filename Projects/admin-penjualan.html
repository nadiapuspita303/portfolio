Sampel Soal – Admin Penjualan

Microsoft Excel

Workbook Microsoft Excel untuk latihan sampel soal administrasi penjualan.

Project Overview

Project Overview

Project Background

Project ini merupakan simulasi pengolahan data administrasi penjualan menggunakan Microsoft Excel yang dirancang untuk melatih kemampuan mengelola data transaksi secara sistematis. Studi kasus mencakup proses pembersihan data, pengambilan informasi dari tabel referensi, transformasi data tanggal, serta analisis sederhana terhadap aktivitas pelanggan. Melalui project ini, saya menerapkan berbagai fungsi Excel untuk menghasilkan data yang lebih akurat, konsisten, dan siap digunakan sebagai dasar pelaporan maupun analisis operasional.

Project Objective

Bertujuan untuk meningkatkan kemampuan dalam mengolah data administrasi penjualan menggunakan Microsoft Excel melalui penerapan fungsi dan formula sesuai kebutuhan operasional. Selain melatih pemahaman terhadap struktur data transaksi dan hubungan antar informasi, project ini juga mengembangkan ketelitian, kemampuan analisis, serta penyelesaian permasalahan dalam menghasilkan data penjualan yang akurat, konsisten, dan siap digunakan untuk kebutuhan pelaporan.

Task / Use Case

Task / Use Case

Ringkasan singkat tugas atau skenario penggunaan yang diselesaikan pada sampel soal ini.

  • Membersihkan kode pelanggan agar memiliki format yang konsisten sebelum dilakukan proses pengolahan data.
  • Menghubungkan data transaksi dengan master customer untuk menampilkan informasi pelanggan secara otomatis.
  • Mengubah tanggal transaksi menjadi periode laporan bulanan menggunakan fungsi bulan-tahun.
  • Menghitung jumlah transaksi yang dilakukan oleh pelanggan yang sama dalam periode laporan yang sama.
  • Menyusun formula yang dapat diterapkan secara konsisten pada seluruh data transaksi tanpa melakukan input manual.

Process / Workflow

Process / Workflow

1

Dataset

Memahami struktur dataset transaksi penjualan beserta hubungan antara data transaksi dan master customer.

2

Mengolah/menghitung data

Membersihkan kode customer menggunakan fungsi pengolahan teks agar format data konsisten. Menghubungkan data transaksi dengan tabel referensi untuk menampilkan nama customer secara otomatis. Mengubah tanggal transaksi menjadi format periode bulanan sebagai dasar pelaporan serta menyusun formula untuk menghitung jumlah transaksi berdasarkan customer dan periode yang sama.

3

Pengecekan Akhir

Melakukan pengecekan akhir untuk memastikan seluruh hasil perhitungan dan informasi yang ditampilkan telah akurat dan konsisten.
