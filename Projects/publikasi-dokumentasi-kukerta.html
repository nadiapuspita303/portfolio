Project Overview

Project Overview

Project Background

Selama pelaksanaan Kukerta Universitas Riau 2024 di Desa Koto Tuo, berbagai media visual dikembangkan untuk mendukung kebutuhan publikasi dan komunikasi tim, mulai dari logo, ID Card, flyer kegiatan, hingga konten media sosial.

Project Objective

Menciptakan identitas visual yang konsisten sekaligus menghasilkan materi publikasi yang informatif, menarik, dan mudah digunakan pada berbagai media komunikasi.
