Dashboard

Sales Performance Dashboard

Sample Superstore 2014-2017 Tableau Excel

Dashboard interaktif untuk menganalisis performa penjualan berdasarkan produk, kategori, wilayah, dan waktu guna mendukung pengambilan keputusan bisnis.

Project Overview

Project Overview

Project Background

Data penjualan mengandung berbagai informasi penting, namun sulit dianalisis apabila hanya disajikan dalam bentuk tabel. Dashboard ini dikembangkan untuk menyajikan performa penjualan secara visual sehingga tren dan pola penjualan dapat dipahami dengan lebih mudah.

Project Objective

Dashboard ini bertujuan untuk menganalisis performa penjualan, membandingkan kontribusi setiap kategori dan wilayah, serta membantu memperoleh insight melalui visualisasi interaktif.

Dataset

Dataset

Sumber Data Sample Superstore
Periode Data 2014–2017
Jumlah Data 9.994 baris
Sales Order Date Profit Category Region Year Products

Data Preparation

Data Preparation

Data Cleaning

  • Memeriksa nilai kosong (missing values) pada data transaksi.
  • Memastikan tipe data (mis. tanggal, angka) sesuai.
  • Memeriksa data duplikat/tidak relevan.

Data Transformation

  • Mengelompokkan data berdasarkan category dan region.
  • Menghitung total sales dan profit.
  • Menyiapkan calculated field baru untuk digunakan sebagai dimensi atau measure pada dashboard.
  • Mengubah format tanggal menjadi Year-Month untuk analisis tren.

Insights

Insights

Key Findings

  • Technology menjadi kategori dengan penjualan tertinggi.
  • Wilayah West memberikan kontribusi penjualan terbesar.
  • Penjualan menunjukkan tren meningkat pada beberapa periode.

Recommendations

  • Mempertahankan performa kategori dengan penjualan tertinggi.
  • Ekspansi ke wilayah lain dengan potensi penjualan yang tinggi.
  • Mengevaluasi produk yang memiliki profit rendah.
  • Memanfaatkan tren penjualan untuk strategi promosi dan stok produk.
